# fuzzy-vibe
The project contains:
* 9 skills for ai-driven fuzzy sphere numerics
* 1 recommended AGENTS.md file, which should sit on the root directory of the working directory.

The AGENTS.md is to push the agent to the goal rather than attempting an ineffective solution or even wandering around the task. Two such behaviors have been observed:
* the agent may stop increasing the quality of the spectrum and try a lot to explain the bad spectrum by some hand-waving theory or just by saying "these are unsolvable massive states".
* the agent may focus on one model with certain interactions and do lots of meaningless tuning and re-interpreting to increase the quality. but it's usually wiser to change the interaction and re-tune.
