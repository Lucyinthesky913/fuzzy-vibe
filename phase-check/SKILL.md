# general strategy
First check the phase on both sides of critical point theoretically. Then only tuning away the relevant parameters to see if other irrelevant parameters will work out the right phases. Below is some known cases as hints. Even for these cases, you may find better way.

# known cases
* symmetry-breaking transition: The phases we need should have the right ground state degeneracies. Moreover, we should test the order parameter if possible.
* transition involving fQHE: Check the entanglement spectrum and the energy spectrum.
* transition with order parameter: Check the order parameter.
